# AutoPro Parts Website

Static auto-parts storefront prototype with:

- Auto-parts product catalog
- Vehicle brand catalog for Toyota, Nissan, Mazda, Isuzu, Mitsubishi, Hino, Suzuki, Ford, Chevrolet, and Honda
- Brand, keyword, and vehicle fitment filters
- Product detail pages with gallery, specs, stock, warranty, and compatible vehicles
- Manual QR payment demo
- Payment/order confirmation design explaining order IDs, unique QR references, gateway webhooks, and admin statuses
- Shopee and TikTok Shop links
- Quote list with WhatsApp request link
- Homepage sections explaining trust features, marketplace strategy, and improvement steps

## Customize before launch

1. Replace demo contact details in `index.html`, `product.html`, and `products.js`.
2. Replace product images, prices, SKU values, OEM references, stock counts, and warranty details in `products.js`.
3. Replace Shopee and TikTok Shop demo URLs with your real listing URLs.
4. Replace the demo QR flow with an official bank/e-wallet QR or payment gateway integration.
5. Add a backend checkout with order records, payment records, gateway webhooks, admin notifications, stock sync, invoices, and delivery tracking.

Open `index.html` in a browser to preview the site.

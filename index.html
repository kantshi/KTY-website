How to know the user ordered and paid

A static website can show a cart and QR payment instructions, but it cannot reliably confirm payment by itself. For real confirmation, build this flow:

  1. Customer submits checkout form.
  2. Website backend saves an order with status Pending Payment.
  3. Payment gateway creates a unique QR code for that exact order ID and amount.
  4. Customer pays by QR.
  5. Gateway sends a webhook to your website after successful payment.
  6. Website updates order status to Paid and notifies you.
